# ＝LOVEイントロクイズ

＝LOVE（イコールラブ）の楽曲イントロを聞いて曲名を当てる、ブラウザで遊べる自分専用のミニゲームです。フレームワークを使わない素のHTML / CSS / JavaScriptで開発しています。

> **このリポジトリには、実在する＝LOVEの楽曲音源は含まれていません。**
> 音源はローカル環境のみで管理する方針のため、GitHub上には公開していません。詳しくは「[音源について](#音源について)」をご覧ください。

## このアプリでできること

- スタート画面で「出題数」（5問 / 10問 / 20問 / 50問 / 全曲）と「カテゴリ」（表題曲のみ / 表題曲＋全員曲 / 全曲）を選んでスタート
- イントロ音源を聞いて、4択から曲名を回答（スキップ・答えを見る、にも対応）
- 制限時間による強制終了はなく、回答の早さに応じた段階式スコアリング
- 全問終了後に、合計得点・ランク（S/A/B/C）・自己ベスト・1問ごとの正誤内訳を表示
- 出題数・カテゴリの組み合わせごとに自己ベストを記録
- 特別称号（実績）システム：全問正解・スピード・レア実績などの称号を獲得できる。称号一覧で獲得状況を確認可能
- プレイ履歴：過去のプレイ結果を新しい順に一覧できる専用画面（総プレイ回数・総回答数・全体正答率のサマリー付き）。各回をタップすると、曲別の正誤内訳（プレイ履歴詳細画面）も確認できる
- 収録曲一覧：81曲をシングル単位のアコーディオンで一覧し、試聴（再生位置バー付き）も可能
- 結果画面から、今回間違えた曲だけを復習する4択クイズを開始できる
- クイズの途中でも、確認モーダルを経由してタイトル画面へ戻れる
- 特別モード：通常プレイとは違う遊び方をまとめた入口
  - 苦手曲モード：プレイ履歴から正答率の低い曲を自動判定し、集中的に練習できる
  - オリジナル問題作成モード：好きな曲だけを選んで自分専用の問題セットを作成・保存・複製・削除できる。曲名・読み仮名での検索、各曲の試聴（共通ミニプレイヤー）にも対応
- ルール説明モーダル（得点表・ランク基準・カテゴリの意味を確認できる）
- PWA対応：ホーム画面に追加してアプリのように起動でき、一度読み込んだ音源はオフラインでもプレイ可能

## 技術構成

- HTML / CSS / JavaScript（フレームワーク・ライブラリ不使用）
- JavaScriptはES Modules（`import` / `export`）でファイルを分割
- PWA（Progressive Web App）：`manifest.json` + Service Worker（`sw.js`）でアプリ本体をキャッシュし、ホーム画面への追加・オフライン起動に対応
- 音源は`assets/audio/local/`の静的ファイルではなく、利用者が選んだmp3をIndexedDBに端末内保存する方式（詳しくは下記「音源について」）
- Google Fonts（M PLUS Rounded 1c）

## ローカルでの起動方法

このアプリはES Modulesを使用しているため、`index.html`をダブルクリックして直接開いても動作しません（ブラウザのセキュリティ制限のため）。簡易的なローカルサーバーを経由して開いてください。

**VSCodeの「Live Server」拡張機能を使う場合**

1. VSCodeでこのフォルダを開く
2. `index.html`を右クリック →「Open with Live Server」を選択

## 開発用ツール

`dev/preview.html`は、特別称号（実績）のアイコン・見た目を、実際にプレイしなくても一覧確認できる開発用のプレビューページです。

- 結果画面で称号を獲得したときのチップ（サンプル5件）
- 称号一覧モーダルのカード（全件、解放済み表示）

をまとめて表示します。保存データ（localStorage）は書き換えません。ゲーム本編（`index.html`）からは一切読み込まれないため、通常のプレイには影響しません。

**使い方**：VSCodeで`dev/preview.html`を右クリック →「Open with Live Server」。

称号のデザインを調整するときは、実際にプレイして条件を満たさなくても、このページを開くだけで見た目を確認できます。

`dev/lyricsEditor.html`は、歌詞データの各行の再生タイミング（開始・終了秒）を、実際に音源を聴きながら微調整するための開発用ツールです。

- 曲を選んで音源・既存の歌詞データを読み込む
- 解析ツールが出力したJSON（またはこのツールで書き出したJSON）を取り込む
- 各行のstart/endを、数値入力・±0.1/±0.5秒ボタン・「今の位置に」ボタンで調整する
- 調整結果をIndexedDBへ保存、またはJSONとして書き出す

歌詞本文の入力・追加・削除はこのツールの対象外です（タイミングの微調整のみ）。ゲーム本編（`index.html`）からは一切読み込まれないため、通常のプレイには影響しません。

**使い方**：VSCodeで`dev/lyricsEditor.html`を右クリック →「Open with Live Server」。

**称号を追加・変更したときに、あわせて更新する箇所**
- `js/titleDefinitions.js`：称号本体の定義（ここが本編の唯一の正）
- `js/titleIcons.js`：アイコンのSVG（新しい称号にはここにも1件追加）
- `dev/debugPreview.js`の`sampleEvents`：**結果画面チップのプレビューに表示したい場合は、ここにも手動で1件追加する**（自動では反映されません。うっかり追加を忘れても本編の動作には影響しませんが、プレビューには出てこないので、称号を増やしたときはこのチェックリストを見て思い出してください）

## 音源について

このアプリは「実在する＝LOVEの楽曲イントロを当てる」ことを目的としていますが、著作権の関係上、本物の楽曲音源はこのリポジトリには含めていません。

- 曲データ（`js/data/songs.js`）に曲名・選択肢などの情報を管理しますが、対応するイントロ音源そのものはこのコードには含まれません
- 音源は、利用者（本人）が自分の端末で選んだmp3ファイルを、スタート画面の「音源を読み込む」からブラウザのIndexedDB（端末内の保存領域）に読み込む方式にしています。読み込んだ音源は各端末のブラウザ内に留まり、サーバーやGitHubには一切送信・保存されません
- `assets/audio/local/`は、開発環境で音源ファイルを一時的に置いておくための場所で、`.gitignore`で除外されGitHubにはアップロードされません。アプリ本体はこのフォルダを直接参照しません
- コード（HTML / CSS / JavaScript）は公開できる形を意識して管理しますが、音源そのものはあくまで個人の私的利用の範囲で管理します
