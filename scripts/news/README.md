# ＝LOVE 最新情報の自動取得（本人用の説明）

公式サイト（https://equal-love.jp/）の NEWS の一覧から、**タイトル・発表日・カテゴリ・記事の URL だけ**を集めて、
アプリの「＝LOVE 最新情報」に出します。YouTube 出演図鑑の自動更新（scripts/youtube/）と同じ公開の仕組みに乗っていますが、手順は別です。

**新しい設定・キー・アカウントは要りません。**（公式サイトの公開のページを読むだけ。YouTube のキーも使いません）

---

## 全体の形
```
毎週月曜 3時（Apps Script の合図）・毎週木曜（予備の定期実行）・master への push
        ▼
GitHub Actions「Deploy to GitHub Pages」
  1. YouTube のデータを作る（前のまま・変えていない）
  2. ＝LOVE 最新情報のデータを作る（scripts/news/refresh-news.mjs）← 失敗しても 1 と公開は止めない
     - NEWS の一覧の1ページ目（新しい記事が続けば最大5ページ）と DISCOGRAPHY の1ページ目を読む。3秒ずつ空ける
     - 前に公開したデータ（公開中のサイトの data/official-news.json）から過去の分を引き継ぐ
     - data/official-news.json を作り、Pages にだけ載せる（git にはコミットしない）
  3. YouTube の取得に失敗して「公開しない」と決めたときでも、ニュースが新しく取れたら、
     YouTube は前のデータ（30日以内）のままでサイトを公開し直す（YouTube の API は呼ばない）
        ▼
アプリ「＝LOVE 最新情報」：最終取得の日時を出す。8日以上取れていなければ「更新が止まっています」
```
- ふだんの1回のアクセスは2回（NEWS の1ページ目・DISCOGRAPHY の1ページ目）。週に2〜3回
- 費用：無料（GitHub Actions は公開リポジトリなら無料。公式サイトの公開ページを読むだけ）

## 取るもの・取らないもの
| 取る | 取らない |
|---|---|
| 記事の ID・タイトル（一覧の表示のまま）・発表日・カテゴリ・公式の URL・取得した日時 | 本文・画像・サムネイル |
| 関連メンバー（タイトルに ＝LOVE のメンバーの姓名があるときだけ） | 名前が書いていないメンバーの推定 |
| 印：訂正・延期・中止・変更・終了（タイトルに書いてあるときだけ） | 本文を読んでの判断 |
| DISCOGRAPHY の作品名・種類・発売日（アプリの図鑑に無い作品を「確認待ち」に出すだけ） | 図鑑・個人ページのデータの自動の書き換え |

## 規約・負荷
- robots.txt（2026-11-03 確認）：`User-agent: *` だけで、禁止の場所は無い
- 公式サイトのページから利用規約・転載の決まりのページは見つからなかった。事実の情報（タイトル・日付）だけを、出典のリンク付きで出す
- 名乗る：User-Agent に「EqualLoveIntroQuiz-NewsCheck/1.0（個人のファンアプリ・アプリの URL）」
- 3秒空ける・20秒で打ち切る・やり直しは1回だけ・最大6回のアクセス

## X（旧 Twitter）は使わない
- X の API は 2026年2月から従量課金で、新しい無料枠が無い（読み取りも有料。カードの登録が要る）
- ログインせずに読む（スクレイピング）は X の規約で禁止 → どちらも採用しない

## 困ったとき
| 届いたもの | 意味 | すること |
|---|---|---|
| GitHub の Issue「＝LOVE 最新情報の自動取得：確認が必要です」の「取得に失敗」 | 公式サイトが落ちていた・形が変わった | 1回だけなら様子を見る（次の回で直れば OK）。続くなら、公式サイトの形が変わった可能性 → Claude に「scripts/news の一覧の読み方を直して」と頼む |
| 同じ Issue の「確認待ちの作品」 | 公式の DISCOGRAPHY に、アプリの CD・特典映像図鑑に無い作品がある | 作品のページで収録内容を確かめ、図鑑に足すか決める（足すのは手で。Claude に頼んでよい） |
| 同じ Issue の「見当たらなくなった記事」 | 公式の一覧から記事が消えた（削除・差し替え） | 公式サイトで確かめる。アプリでは消さずに「見当たらない」の印を付けて出している |
| 同じ Issue の「知らないカテゴリ」 | 公式の NEWS のカテゴリが増えた | アプリでは「その他」に入れている。必要なら js/officialNewsData.js のカテゴリに足す |
| アプリに「最新情報の更新が止まっています」 | 8日以上、取得できていない | GitHub の［Actions］で「Deploy to GitHub Pages」が動いているか見る。YouTube の更新も止まっていれば、合図（Apps Script）のトークンを確かめる（scripts/youtube/SETUP.md） |

- 手で動かす：GitHub の［Actions］→「Deploy to GitHub Pages」→［Run workflow］
- 手元で試す（ネットを使わない）：`node scripts/news/refresh-news.mjs --trigger push --from-html <保存した HTML のフォルダ>`
